# Astreintes

Appli de disponibilités et de planning d'astreinte pour un centre de secours.

- `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `icons/`, `fonts/`, `chunks/` : le site.
- `config.js` : la configuration Firebase du centre (à remplir, voir le guide).
- `firestore.rules` : les règles de sécurité à coller dans Firebase.
- `rappels/` et `.github/workflows/rappels.yml` : le programme qui envoie les rappels automatiques.

Adresses utiles une fois en ligne :
- pompiers : la même adresse pour tous ; chacun choisit son nom à la première ouverture ;
- chef de centre : l'adresse du site suivie de `#chef`.

Toute la mise en place est décrite pas à pas dans le guide fourni avec ce dossier.
